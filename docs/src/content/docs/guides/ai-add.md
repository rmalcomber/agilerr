AI Add runs a short planning conversation attached to a project or parent item. It asks one question at a time, then proposes items. You **accept, reject or edit each proposal** before anything is created.

To enable it, set `OPENAI_API_KEY` (and optionally `OPENAI_BASE_URL` and `OPENAI_MODEL`) before starting Agilerr. See [configuration](../../getting-started/configuration/).

Without it, everything else works as normal.
