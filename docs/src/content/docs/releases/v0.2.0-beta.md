## What's new

- Agilerr is described as **beta** everywhere: README, release archive readme, website and docs.
- A complete documentation site: concepts, guides with screenshots, the REST API with a page per resource, MCP, reference and troubleshooting.
- GitHub releases of tags containing a `-` are published as **pre-releases**, and the Docker `latest` tag only moves for stable releases.

## Upgrading

Back up your data directory first (see [Versions and upgrades](/reference/upgrades/)), then replace the binary or pull the image. No schema change.
