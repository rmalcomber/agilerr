## How versions work

Agilerr follows [semantic versioning](https://semver.org). While it is `0.x` and tagged `beta`, anything can change between releases, including the data layout and the REST API. Release notes say when an upgrade needs attention. Back up your data directory before upgrading: see [Versions and upgrades](/reference/upgrades/).
