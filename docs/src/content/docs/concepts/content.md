## Markdown

Item **descriptions** and **comments** support Markdown: headings, lists, emphasis, links and code. Descriptions are collapsed by default in the backlog, so long hierarchies stay readable. Open the chevron on a card to read the full text.

## Tags

Tags are free-text labels on projects and items. They are trimmed and de-duplicated without regard to case. Use them to cross-cut the hierarchy, for example `auth`, `billing` or `mvp`. The backlog can be filtered by tag.

## Mentions

In the add and edit forms you can **mention users** and **mention other items**. Each mention references the user or item by its id. Comments support mentions too.

## Comments

Every item has a comment thread. You need **View Units** to read comments and **Edit Units** to add them. The card shows a comment count.
