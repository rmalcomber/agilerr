## Planning

- **Backlog.** The whole tree, filterable. [Backlog guide](/guides/backlog/).
- **Hierarchy.** Project → Epic → Feature → User Story → Task. [Concepts](/concepts/hierarchy/).
- **Kanban.** Move work between lanes. [Kanban guide](/guides/kanban/).
- **Dashboard.** Where the work stands at a glance. [Dashboard guide](/guides/dashboard/).
- **Add and edit items** with Markdown, tags, colours and assignees. [Items](/guides/items/).

## Quality

- **Bugs** live outside the hierarchy, start in **triage** and carry a priority. [Bugs](/guides/bugs/).

## Teams

- **Projects and settings.** [Projects](/guides/projects/).
- **Users and per-project permissions.** [Users and permissions](/guides/users-and-permissions/), [Permissions model](/concepts/permissions/).
- **Deleting and recovery.** Soft delete, restore, purge. [Deleting](/guides/deleting/).
- **Keyboard shortcuts.** [Shortcuts](/guides/shortcuts/).

## AI and automation

- **AI Add.** An optional planning conversation that proposes epics, features and stories for you to review. [AI Add](/guides/ai-add/).
- **REST API.** One page per resource. [REST API](/integrations/rest-api/).
- **MCP.** Over HTTP or stdio, three tools. [MCP](/integrations/mcp/).

## Running it

- **One binary** for Linux, macOS and Windows, or a **Docker** image. [Install](/getting-started/install/).
- **Embedded PocketBase**: no database to run. [Architecture](/reference/architecture/).
- **Configured with environment variables.** [Environment variables](/reference/environment-variables/).
